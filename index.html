مفتاح الحفظ على الموقع

ليحفظ الموقع الإضافة والتعديل والحذف يحتاج مفتاحًا من GitHub خاصًا بمستودع الموقع. يُنشأ مرة واحدة، ويُحفظ على هذا الجهاز فقط.

  1. افتح صفحة إنشاء مفتاح في GitHub وأنت داخل بحساب مالك المنظمة.
  2. اكتب اسمًا مثل «دليل المدارس»، واختر مدة الصلاحية.
  3. في Resource owner اختر makkah-schools.
  4. في Repository access اختر Only select repositories ثم makkah-schools.github.io.
  5. في Permissions افتح Repository permissions واجعل Contents على Read and write.
  6. اضغط Generate token وانسخ المفتاح والصقه هنا.
