# دليل مدارس منطقة مكة المكرمة

صفحة للبحث في مدارس منطقة مكة المكرمة (1,710 مدرسة) بالاسم أو الرقم الوزاري أو اسم المدير، مع التصفية بالقطاع والمحافظة والمرحلة والجنس ونوع التعليم، وتقارير الأعداد، والطباعة، والتصدير إلى Excel.

## الملفات

| الملف | ما فيه |
|---|---|
| `index.html` و`style.css` و`app.js` | الصفحة وتصميمها وعملها |
| `search.js` | محرك البحث الذكي (الهمزات، الأخطاء الإملائية، الأعداد المكتوبة بالحروف، لوحة المفاتيح الإنجليزية) |
| `data.js` | بيانات المدارس (دون البيانات الشخصية)، يُنشأ من ملف Excel |
| `secure.js` | هوية المدير وجواله وبريده، مشفّرة بكلمة مرور الإدارة (AES-256-GCM) |
| `tools/prepare.py` | يحوّل ملف Excel إلى `data.js` |
| `tools/sectors-makkah.json` | قطاعات مدارس مكة المكرمة (الشمال، الجنوب، الشرق، الغرب) والجموم وبحرة |

## تحديث البيانات من ملف Excel جديد

يجب أن يكون الملف بالأعمدة نفسها: الرقم الوزاري، اسم المدرسة، المدينة/القرية، المرحلة، مكتب التعليم، جنس المدرسة، نوع التعليم، اسم مدير المدرسة…

```
pip install openpyxl cryptography
SCHOOL_ADMIN_PASSWORD='كلمة مرور الإدارة' python3 tools/prepare.py "مسار ملف الإكسل.xlsx"
```

ثم شغّل `python3 tools/stamp.py` ليحدّث أرقام النسخ في `index.html` حتى تحمّل المتصفحات الملفات الجديدة، وارفع `data.js` و`secure.js` و`index.html` إلى المستودع. لتغيير كلمة المرور شغّل الأمر نفسه بكلمة مرور جديدة. يُقرأ تاريخ البيانات من اسم الملف إن كان فيه تاريخ مثل `1448-5-30`.

## الصلاحيات

| المستخدم | ما يستطيعه |
|---|---|
| أي زائر | البحث والاطلاع على بيانات المدارس، التقارير، الرسوم البيانية، التصدير، الطباعة — دون كلمة مرور |
| «دخول الإدارة» بكلمة مرور الاطلاع | يرى أيضًا هوية المدير وجواله وبريده (مشفّرة في `secure.js`) — دون تعديل |
| «المسؤول» (wra003@hotmail.com فقط) | الإضافة والتعديل والحذف، وبيانات الوكيل/ة (الاسم، الرقم، الهوية) |

دخول المسؤول عبر Firebase Authentication (مشروع `makkah-schools`، الدخول بالبريد وكلمة المرور، التسجيل الذاتي مقفل). زر «نسيت كلمة المرور؟» يرسل رابط تعيين كلمة مرور جديدة إلى wra003@hotmail.com فقط.

بيانات الوكلاء ومفتاح GitHub ومفتاح فك تشفير `secure.js` محفوظة في Firebase Realtime Database تحت `editor/`، وقواعدها تسمح بالقراءة والكتابة لحساب wra003@hotmail.com فقط. بيانات الوكلاء لا تُكتب في المستودع.

كل حفظ من المسؤول يكتب `data.js` و`secure.js` و`index.html` في commit واحد عبر GitHub API، فيظهر التغيير للجميع خلال دقائق، ويبقى في سجل التعديلات.

تنبيه: تشغيل `tools/prepare.py` على ملف Excel جديد يستبدل بيانات المدارس كلها، ومنها ما أُضيف أو عُدّل من الموقع (بيانات الوكلاء في Firebase لا تتأثر).

## الخصوصية

الموقع والمستودع عامّان، لذلك لا يكتب `prepare.py` في `data.js` أرقام الهويات ولا الجوالات ولا البريد. هذه البيانات في `secure.js` مشفّرة، ولا تُفك إلا في المتصفح بعد إدخال كلمة مرور الإدارة من زر «دخول الإدارة». كلمة المرور نفسها لا تُحفظ في المستودع. ملف Excel الأصلي لا يُرفع إلى المستودع (`.gitignore` يمنع ملفات xlsx).
